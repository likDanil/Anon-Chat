# Anon Chat — анонимный P2P‑чат

Локальный чат с шифрованием. Сообщения идут напрямую между пользователями, без центрального сервера (в режиме P2P) или через туннель, если P2P недоступен.

> **Цель проекта** — личная переписка между доверенными людьми, обучение и эксперименты. Никакой скрытой функциональности, никаких бэкдоров. Исходный код открыт — можно проверить.  
> Проект не предназначен для использования во вред, в незаконных целях или для деятельности, угрожающей безопасности. Только легитимное применение.

## Возможности

- **Шифрование** — AES, ключ из сид‑фразы
- **Два режима** — P2P (PeerJS/WebRTC) и туннель (CloudPub)
- **Текст, фото, голосовые** — сжатие и шифрование
- **Кто в сети** — список онлайн в шапке
- **Без аккаунтов** — достаточно сид‑фразы
- **Локальное хранение** — история только в браузере

## Быстрый старт

### 1. Установка

```bash
git clone https://github.com/likDanil/Anon-Chat.git
cd Anon-Chat
npm install
```

### 2. Режим P2P (оба на localhost)

Оба пользователя:

1. Запустить `Запустить чат.bat` (или `node launcher.js`)
2. Ввести имя, сид‑фразу и **одинаковый код чата**
3. Писать сообщения

Трафик идёт напрямую через WebRTC (STUN/TURN).

### 3. Режим туннеля (если P2P не работает)

Один пользователь:

1. Запустить `Запустить чат (если не подключается).bat`
2. Отправить другу ссылку CloudPub и сид‑фразу
3. Друг открывает ссылку — чат без настройки

Трафик идёт через CloudPub и ваш локальный сервер.

## Настройка CloudPub (туннель)

Туннель использует [CloudPub](https://cloudpub.ru/).

1. Скачайте **CLI**: https://cloudpub.ru/docs/ → «Утилита командной строки»
2. Распакуйте ZIP в папку (например `C:\clo`)
3. Добавьте папку в PATH:
   - Win+R → `sysdm.cpl` → Enter
   - «Дополнительно» → «Переменные среды»
   - Path → «Изменить» → «Создать» → путь к папке
4. Выполните: `clo login`
5. Bat‑файл сам подхватит CloudPub

## Структура проекта

```
├── chat2.html              # UI чата
├── server.js               # HTTP‑сервер, poll, presence
├── launcher.js             # P2P: сервер + localhost
├── launcher-tunnel.js      # Туннель: сервер + CloudPub
├── Запустить чат.bat
└── Запустить чат (если не подключается).bat
```

## Приватность

- **P2P**: сообщения идут напрямую, PeerJS используется только для установки соединения
- **Туннель**: сервер получает только зашифрованные строки, ключ только у участников
- **Сохранение**: история хранится в localStorage/браузере, не на сервере

## Технологии

- Node.js, vanilla JS
- PeerJS (WebRTC)
- CryptoJS (AES)
- CloudPub (туннель)
- WebSocket (localhost)

## Альтернативы

**[scrap-gram](https://github.com/sendox2012-debug/scrap-gram)** — мессенджер на Gun.js. Работает в браузере: открыл ссылку, ввёл ключ комнаты - можно чатиться без установки. Позиционируется как «без сервера», но данные идут через ноды Gun.js и peer.ooo - это сторонние сервисы. P2P через их relay, не прямое соединение. Есть приватные комнаты с шифрованием. Удобно для быстрого обмена, если ок доверять чужой инфраструктуре.
